# Game
CSE3120 Game Contest 2 Project by Samuel Borges and Alejandro Moreno

Project name: Improved Connect 4

# Instruction on how to run
- Ensure you are using a 32-bit environment with MASM and Irvine32 libraries installed.

- Clone the repository and build the <game.asm> file.
  
- Run the debugger to view the grid and follow the prompts for further instructions.

# How to win

Players take turns selecting columns to drop their colored discs. Whoever forms a line of four discs first wins, and the game ends immediately.
